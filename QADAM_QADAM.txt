BUXDU SCOPUS — RASMIY H-INDEX YANGILANISHI

GitHub repository root papkasida FAQAT 2 ta faylni almashtiring:
1) update_scopus.py
2) index.html

Boshqa fayllarga tegmang.
ELSEVIER_API_KEY Secret o'sha holatda qoladi.
Workflow faylini o'zgartirish shart emas.

NIMA QO'SHILDI
- Elsevier Scopus Author Retrieval API, view=METRICS.
- Rasmiy Scopus h-index.
- Rasmiy Scopus document-count.
- Scopus citations-count va cited-by-count.
- TOP mualliflarda rasmiy h-index chiqadi.
- Muallif profilida Scopus jami va BuxDU baza ko'rsatkichlari alohida.
- Dataset h-index fallback sifatida saqlanadi.

API YUKLAMASI
- CSVda taxminan minglab noyob muallif bo'lishi mumkin.
- Birinchi ishga tushishda eng ko'p hujjatli 200 muallif API orqali olinadi.
- Keyingi kunlik workflowlarda navbatdagi 200 muallif to'ldiriladi.
- Shu sabab TOP mualliflar birinchi ishga tushishda rasmiy metrikaga ega bo'lishi kerak.
- Author cache 30 kun saqlanadi.
- Author cache data/api_cache ichida saqlanadi, shuning uchun eski workflow uni avtomatik commit qiladi.

KEYINGI QADAM
1. GitHub root'dagi update_scopus.py ni shu fayl bilan almashtiring.
2. index.html ni shu fayl bilan almashtiring.
3. Commit changes.
4. Actions -> Update Scopus enriched data -> Run workflow.
5. Workflow yashil bo'lgach scopus_enriched.csv yangilanadi.
6. GitHub Pages sahifasini Ctrl+F5 bilan yangilang.

Agar Author Retrieval API uchun ruxsat bo'lmasa, workflow kvartil qismini baribir yangilaydi
va panel CSV h-index fallbackini ko'rsatadi. Actions logida 401/403 xabari ko'rinadi.
